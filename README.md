## 🌐 GitHub Pages वर Live कसे करायचे (Step-by-Step Guide in Marathi)

तुम्ही ही वेबसाइट **GitHub Pages** च्या माध्यमातून **100% मोफत (Free)** आणि कायमस्वरूपी Live करू शकता. खालील सोप्या स्टेप्स फॉलो करा:

### Step 1: GitHub वर नवीन Repository तयार करा
1. तुमच्या ब्राउझरमध्ये [https://github.com](https://github.com) वर जाऊन लॉगिन (Login) करा.
2. उजव्या कोपऱ्यात वरच्या बाजूला **`+`** चिन्हावर क्लिक करा आणि **`New repository`** निवडा.
3. **Repository name** मध्ये लिहा:
   - पर्याय १ (बेस्ट): `<तुमचे-github-username>.github.io` (उदा. `omkarsonpitre.github.io`)
   - पर्याय २: `portfolio`
4. हे **Public** ठेवा (Private ठेवल्यास फ्री GitHub Pages चालणार नाही).
5. खालील **Create repository** बटणावर क्लिक करा.

### Step 2: फाईल्स Upload करा
1. नवीन Repository उघडल्यावर **"uploading an existing file"** या लिंकवर क्लिक करा.
2. तुमच्या कॉम्प्युटरमधील खालील फाईल्स सिलेक्ट करून ड्रॅग & ड्रॉप (Drag & Drop) करा:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. खाली **Commit changes** बटणावर क्लिक करा.

### Step 3: GitHub Pages सुरू करा (Settings)
1. तुमच्या Repository च्या वरच्या मेनूमध्ये **Settings** वर क्लिक करा.
2. डाव्या बाजूच्या मेनूमध्ये **Pages** वर क्लिक करा.
3. **Build and deployment** खाली:
   - **Source**: `Deploy from a branch` निवडा.
   - **Branch**: `main` (किंवा `master`) निवडा आणि फोल्डर `/ (root)` ठेवा.
4. **Save** बटणावर क्लिक करा.

### Step 4: तुमची वेबसाइट Live झाली! 🎉
- साधारण १ ते २ मिनिटांत GitHub Pages तुमच्या वेबसाइटची लिंक देईल:
  👉 `https://<तुमचे-username>.github.io/` (किंवा `https://<तुमचे-username>.github.io/portfolio/`)
- ही लिंक तुम्ही तुमच्या Instagram Bio, LinkedIn, WhatsApp आणि Resume मध्ये जोडू शकता!
